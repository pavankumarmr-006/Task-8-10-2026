Mini Employee Data Project

This is a simple Python project to analyze employee salary data using Pandas and Matplotlib.

What This Project Does
Reads employee data from a CSV file.
Finds the average salary.
Finds the highest salary.
Creates a salary chart.
Dataset

The employees.csv file contains:

name - Employee name
department - Employee department
salary - Employee salary
Tools Used
Python
Pandas
Matplotlib
How to Run

Install the required libraries:

pip install pandas matplotlib


Run the Python file:

python Task15.py


The program will show the employee data, average salary, and highest salary. It will also create a salary_chart.png file.

Results
Average Salary: $57,875
Highest Salary: $72,000
Highest-Paid Employee: David
